## SoundCloud sources

[Clair Obscur: Expedition 33 (Original Soundtrack) by Lorien Testard](https://soundcloud.com/lorientestard/sets/clair-obscur-expedition-33-6) has 154 tracks, genre Soundtrack and a release date of 24 April 2025. Its public page is marked embeddable.

SoundCloud's public album page supplied the playlist's 154 IDs/order and initial metadata. The complete track metadata was then read using the documented `SC.Widget.getSounds()` method while browsing all of the official widget's lazy-loaded playlist rows, with automatic playback disabled. All 154 IDs and their order matched the public page. Durations in the local catalogue are rounded to whole seconds. The playlist or its available tracks may later change; this snapshot does not guarantee continued playback.

The official [oEmbed endpoint](https://soundcloud.com/oembed?format=json&url=https%3A%2F%2Fsoundcloud.com%2Florientestard%2Fsets%2Fclair-obscur-expedition-33-6) identified [the 500×500 artwork](https://i1.sndcdn.com/artworks-5246eafb-d5d0-4181-bdf5-0635133a52b2-0-t500x500.jpg). Creator/source: [Lorien Testard on SoundCloud](https://soundcloud.com/lorientestard). Playlist ID: `2003089700`. The page marks the content **all-rights-reserved**; no separate artwork or music licence has been established. Local inclusion for this requested prototype does not imply permission for unrestricted redistribution or publication.

The first-play notice loads the external widget only after Continue, and links to a local Help article explaining that SoundCloud hosts playback, both interfaces control the same player, and import saves catalogue entries rather than audio files. The draggable widget window retains source/uploader links and can move behind Music using the local window manager. This implementation uses the [official Widget API](https://developers.soundcloud.com/docs/api/html5-widget), without an application API key or downloaded audio.

SoundCloud may receive connection information and use cookies or browser storage when its player loads. Playback is subject to availability, browser/account/region restrictions and uploader settings. The notice also records unresolved terms questions: a visible widget or warning is not confirmation that the collection-style use is permitted, and the feature may change or be discontinued after review of [SoundCloud's terms](https://soundcloud.com/terms-of-use). Audible playback and external-service reliability must be verified separately from static metadata/asset checks.

## Hardware reference sources

The following primary references guided the procedural model; they are links for future research, not runtime network dependencies:

- [Apple M4 MacBook Air specifications](https://support.apple.com/en-au/122209): Midnight finish; 304.1×215 mm footprint; 11.3 mm **closed assembly** height; 2560×1664 panel; keyboard layout. The model's approximately 11.68 mm closed envelope and small details remain estimates.
- [Apple M4 Midnight gallery](https://www.apple.com/shop/product/fw123ll/a/Refurbished-13-inch-MacBook-Air-Apple-M4-chip-with-10%E2%80%91Core-CPU-and-8%E2%80%91Core-GPU-Midnight): finish, silhouette, edges, ports and lid references. The source photographs themselves are not used as runtime 3D textures.
- [Apple's M4 Air announcement](https://www.apple.com/newsroom/2025/03/apple-introduces-the-new-macbook-air-with-the-m4-chip-and-a-sky-blue-color/): distinguishes Midnight from lighter Sky Blue.
- [Apple's M2 announcement](https://www.apple.com/newsroom/2022/06/apple-unveils-all-new-macbook-air-supercharged-by-the-new-m2-chip/): a secondary top-down Midnight keyboard reference. This is an M2 photograph used for estimated layout ratios, not an exact M4 drawing; generation/locale legends can differ.
- [Apple SuperDrive connection guide](https://support.apple.com/en-us/102181): USB-C-to-USB adapter topology, not proof that the proposed fixed-cable route reaches without an extension.
- [Apple's historical SuperDrive accessory listing](https://support.apple.com/en-hk/112585): the **Accessories → MacBook Air SuperDrive** entry specifies 139×139×17 mm. The host page describes a Late 2010 Air; its laptop dimensions are not the M4 reference and this is not a verified current accessory-store listing.
- [ECMA-130, second edition](https://dev.ecma-international.org/wp-content/uploads/ECMA-130_2nd_edition_june_1996.pdf), §§8.2, 8.6 and 8.7: 15 mm centre hole, 1.2 mm substrate and 120 mm CD diameter, with manufacturing tolerances. Its [official publication page](https://ecma-international.org/publications-and-standards/standards/ecma-130/) identifies it as a CD-ROM physical standard and references IEC 908 for audio tracks. The representative jewel-case dimensions are modelling assumptions, not specified by this standard.

The virtual menus, Help, About and TextEdit layers are original browser implementations informed by Apple Music references. They do not embed private screenshot pixels, access the owner's native Music library or connect to an Apple account. The real album metadata and artwork come from the public provider sources documented here.
