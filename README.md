# The Collection

An interactive 3D CD collection with a playful, unofficial music desktop. **v1.0.0**

Requires Node.js 20+. No installation or build step.

```sh
node server.mjs
```

Open [the collection](http://127.0.0.1:4319/) or the [desktop preview](http://127.0.0.1:4319/dev/music/).

Run checks with `node checks/run-checks.mjs`.

Music uses SoundCloud and Bandcamp players or external Apple Music links. Imports save catalogue entries, not audio; libraries and preferences stay in your browser.
